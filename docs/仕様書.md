# 住所禄管理システム　要件定義書
## １．プロジェクト概要
### プロジェクト名
- addressbook_system

### 目的
Java Spring Bootを使用したWebアプリケーション開発の学習およびポートフォリオ作成。
本システムを通じて以下の技術要素を習得・実証する。
- Spring Boot
- Maven
- Thymeleaf
- PostgreSQL
- Spring Data JPA
- Validation
- Git/Github
- CRUD

## ２．システム概要
住所録情報を管理するWebシステム。
利用者は連絡先情報の一覧検索表示・編集・登録・削除が出来る。

## ３．開発環境
### 言語
- Java21

### フレームワーク
- Spring Boot

### テンプレートエンジン
- Thymeleaf

### ORM
- Spring Data JPA

### DB
- PostgreSQL

### ビルドツール
- Maven

### IDE
- IntelliJ

### バージョン管理
- Git
- Github

## ４．機能一覧
### ４－１．一覧表示・検索表示
- 表示項目
  - ID
  - 氏名
  - メールアドレス
  - 電話番号

### ４－２．詳細表示
選択した住所禄情報を全部表示する

### ４－３．編集
- 編集項目
  - 氏名
  - メールアドレス
  - 電話番号
  - 郵便番号
  - 住所

### ４－４．登録
- 入力項目
  - 氏名
  - メールアドレス
  - 電話番号
  - 郵便番号
  - 住所

### ４－５．削除
選択した住所禄情報を削除する

## ５．入力チェック
- 氏名
  - 必須
  - 100文字以内
- メールアドレス
  - 必須
  - メールアドレス形式 
- 電話番号
  - 必須
  - 20文字以内
- 郵便番号
  - ハイフンなしに自動修正
- 住所
  - 任意
  - 200文字以内

## ６．画面一覧
- トップ
  - 一覧表示
  - /
- 詳細
  - データ参照
  - /detail/{id}
- 編集
  - データ更新
  - /edit/{id}
- 登録
  - データ登録
  - /new
- 削除
  - データ削除
  - /delete/{id}

## ７．データベース設計
### テーブル名
address

### カラム一覧
| カラム名        | 型            | 備考      |
| ----------- | ------------ | ------- |
| id          | SERIAL       | PK      |
| name        | VARCHAR(100) | 氏名      |
| email       | VARCHAR(100) | メールアドレス |
| phone       | VARCHAR(20)  | 電話番号    |
| postal_code | VARCHAR(20)  | 郵便番号　|
| address    | VARCHAR(200)  | 住所    |
| created\_at | TIMESTAMP    | 登録日時    |
| updated\_at | TIMESTAMP    | 更新日時    |
